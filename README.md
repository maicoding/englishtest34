# Englisch U3/U4 Lernsystem

Statische GitHub-Pages-App fuer schnelles, wiederholbares Training vor den naechsten Arbeiten.

## Start

- `index.html` im Browser oeffnen oder ueber GitHub Pages ausliefern.
- GitHub Pages: Repository Settings -> Pages -> Deploy from branch -> `main` / root.
- Es gibt kein Backend. Lernstand und Fehlertypen werden nur lokal im Browser per `localStorage` gespeichert.

## Inhalt

- Englisch U3/U4: Wortfelder, Word families, Verb + Preposition, Conditionals, Past Perfect, Gerund/Infinitive, Linking Words, Reading Evidence, Writing-Struktur.
- Latein und Mathe sind als weitere Trainingsbereiche im gleichen System enthalten, damit dieselbe Lernlogik weiterverwendet werden kann.
- Papierauftraege fordern bewusst schriftliche Loesungen, damit nicht nur geklickt, sondern aktiv formuliert wird.

## Material

Die wichtigsten vorbereitenden Englisch-Dateien liegen unter `materials/`:

- `Englisch_U3_U4_Trainingsplan.md`
- `Englisch_U4_Grammatik_Klausurtraining.md`
- `Englisch_Reading_Paralleltexte_U3_U4.md`
- `Englisch_Writing_Scaffolds_U3_U4.md`

Unter `edumap/` liegt ein erster Import-Entwurf. Sobald das konkrete Edumap-JSON-Format vorliegt, kann diese Struktur ohne inhaltliche Neuarbeit in das Zielformat gebracht werden.

## Datenschutz

Die App laeuft clientseitig. Es werden keine personenbezogenen Daten an einen Server gesendet.
