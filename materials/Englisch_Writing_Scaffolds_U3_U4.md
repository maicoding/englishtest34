# Englisch: Writing Scaffolds U3/U4

## Ziel

Writing wird in Stufen geuebt, damit freie Texte nicht ueberfordern.

## Stufe 1: Satzstarter zuordnen

| Funktion | Satzstarter |
|---|---|
| Meinung | I think that ... |
| Grund | One reason is that ... |
| Beispiel | For example, ... |
| Folge | This shows that ... |
| Gegensatz | However, ... |
| Schluss | In conclusion, ... |

## Stufe 2: Vier-Satz-Absatz

Thema: Should more girls be encouraged to work in tech?

```text
I think that ...
One reason is that ...
For example, ...
This shows that ...
```

## Stufe 3: Sechs-Satz-Absatz

Thema: Is summer camp a good way to become more independent?

```text
I think that ...
At first, ...
One reason is that ...
For example, ...
However, ...
In conclusion, ...
```

## Stufe 4: 80-100 Woerter

Thema: Is California a good place to live?

Pflicht:

- Meinung.
- Zwei Gruende.
- Ein Beispiel.
- Ein Gegensatz.
- Schluss.

Checkliste:

```text
Did I answer the question?
Did I use linking words?
Did I give at least one example?
Did I check verbs?
Did I check word order?
```

## Feedback bei Fehlern

### Text zu kurz

```text
Add one reason and one example. Do not start a new topic.
```

### Keine Struktur

```text
Mark opinion, reason, example and conclusion in different colours.
```

### Zu viele einfache Saetze

```text
Join two sentences with because, although or however.
```

### Inhalt gut, Sprache schwach

```text
Keep the idea. Correct only verbs and word order first.
```
